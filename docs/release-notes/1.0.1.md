A window onto the world for Android TV / Google TV: spin a night-and-day globe with the remote, dive into a region, watch a wall of live webcams, zap between them in fullscreen, or let the demo mode travel for you.

**What's new in 1.0.1**

- **"Quit lukarne" works again** after a trip to the TV's home screen with the menu open. Before, the menu stayed on screen but the remote went to the globe behind it, so Quit did nothing. Holding BACK no longer opens and closes the menu at once.
- **Update notice.** lukarne now checks this page for a newer version (at most every 6 hours) and shows "Version X is available" on the globe and in Settings, with the address to type in Downloader. It downloads nothing by itself. Installs from a store never check.

**Today's catalogue** (18 October 2026): 831 webcams in 41 regions and 242 places, of which 681 stream live video (300 Caltrans and 100 DelDOT road cameras, 281 YouTube live streams played in YouTube's own player) and 150 are Fintraffic weather cameras (a still every few minutes, shown when *Still images* is on). The list refreshes itself every day; no reinstall needed for that. (The 1.0.0 notes said "~840 live webcams in 40 regions": that was the whole catalogue, stills included.)

**Install (sideload).** On the TV, install the *Downloader* app, allow it to install unknown apps, then enter `github.com/storagebits/lukarne/releases/latest/download/lukarne.apk` (always the newest version). Or from a computer: `adb install lukarne.apk`. Built and tested on an NVIDIA SHIELD (Android 11); Android TV 9 or later is required.

**Updating from 1.0.0:** install the new APK over the old one (same signing key, settings kept). 1.0.0 predates the update notice, so it will not tell you about this release.
